# 규칙 한 줄 포맷
- {ID} {조건이면} {동사로 끝나는 명령} (이유: 10자 이내, 선택)
  예) DS-03 슬라이드 문장을 그대로 읽지 않는다 (청중 이탈)

## ID 체계
- 전역: G-01, G-02 …
- 스킬별: {스킬 약어}-{번호} (DS-01, PR-01)
- 번호는 재사용하지 않는다 (삭제한 규칙 번호는 비워 둔다)

## 이유 (why)
- 한 구절이면 규칙 끝에 (이유: …)
- 그보다 길면 why.md#{ID} 로 옮기고 규칙 줄은 한 줄 유지
- 이유는 지우지 않는다: 모델은 이유를 알아야 경계 사례를 판단한다
- 대문자 MUST·ALWAYS 로 강조하지 말고 이유로 설득한다

## 검사 방식 표시
- (lint): 정규식·카운트로 판정 가능 → lint/forbidden.txt
- (judge): LLM 판정 → evals.json
- 트리거(호출 여부) → trigger-eval.json (별도 파일)

## 금지
- "~하면 좋다", "가능하면", "적절히"
- 배경 설명 문단
- 검증 방법이 없는 규칙
