## 규칙 피드백
| 스킬 | 자동호출(O/X) | 추가 지시(원문) | 유형 | 규칙 후보 | 반복 횟수 |
|---|---|---|---|---|---|

- 유형: 트리거(미호출) / 신규(없는 규칙) / 미준수(있는 규칙을 안 지킴)
- 추가 지시는 요약하지 않고 원문 그대로
- 규칙 후보는 rule-format.md 포맷으로
- 반복 횟수는 이전 리포트에서 같은 후보를 찾아 누적
- 반복 2회 이상 → harness-tidy 로 스킬 반영 + Eval 케이스 추가

| 유형 | 다음 조치 |
|---|---|
| 트리거 | description 에 표현 추가 + trigger-eval.json 에 케이스 추가 (실제 원문 질의) |
| 신규 | Rules 에 새 ID 추가 + evals.json 케이스 추가 |
| 미준수 | 규칙 문장 점검 + 실패 케이스 보강, 가능하면 lint 로 전환 |
