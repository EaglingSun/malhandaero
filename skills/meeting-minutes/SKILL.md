# 회의록 + 할 일 추출 (말한대로 표준)

입력: 회의·통화 녹취 텍스트(화자 표기가 있어도 되고 없어도 된다). 출력: `회의록.md` 한 파일 (+ 요청 시 `할일.json`).
형식의 기준은 `docs/MINUTES_FORMAT.md`다. 이 스킬은 그 형식을 Claude Code에서 바로 쓰기 위한 절차다.

## 절차

1. **누가 나인지 정한다.** 사용자가 말하지 않았으면 화자 목록을 보여 주고 한 번 묻는다. 모르면 "말한 사람이 스스로 하겠다고 한 일"만 내 일로 본다.
2. **오늘 날짜**를 확인한다(기한을 날짜로 바꿀 때 쓴다).
3. 녹취 전체를 한 번에 읽는다(6만 자까지). 더 길면 6만 자 단위로 나눠 읽고 마지막에 합친다.
4. 아래 규칙으로 **JSON**을 먼저 만들고, 그 JSON에서 **Markdown**을 만든다. (JSON → Markdown 순서를 지켜야 할 일과 회의록이 어긋나지 않는다.)
5. 결과를 저장하고, 내 일 건수·맡긴 일 건수·확인할 것 건수를 한 줄로 알려 준다.

## 추출 규칙

할 일(items)
- 앞으로 누군가 해야 하는 일만. 끝난 일·감상·잡담은 제외.
- **묶어서 뽑는다**: 같은 주제·같은 담당자의 잔일은 상위 할 일 1개로 합치고, 잔일은 `details`(각 20자 안팎)에 둔다. 상위 할 일 `text`는 결과가 무엇인지 알 수 있게 '~하기' 꼴 한 줄.
- **내 일(owner=me)은 5개를 넘기지 않는다.** 더 있으면 더 크게 묶는다. 작은 일이라도 빠뜨리지 말고 details에 넣거나, 할 일이 아니면 회의록 요점에 남긴다.
- **담당자 판정**: 이름·화자 표기로 담당자가 불린 일은 반드시 `other`(`who`에 이름). 내가 "~해 주세요"로 시킨 일도 `other`. `unclear`는 아무도 담당을 말하지 않은 일에만.
- `due`는 원문 표현 그대로(예: 금요일까지), `dueDate`는 오늘 기준 가장 가까운 앞날 YYYY-MM-DD, `time`은 시각이 나왔을 때만 HH:MM. `scope`는 회사|개인. `quote`는 근거 원문 한 문장.

회의록(minutes) — 다른 사람에게 그대로 보낼 문서
- `attendees`: 녹취에 나온 참석자 이름·화자 표기.
- `topics`: 주제마다 하나, 회의 순서대로. `topic`은 짧은 제목. `points`는 배경·현황·쟁점을 **3~5개**로 압축(비슷한 말은 합침). `decisions`는 그 주제에서 정해진 것.
- 요점은 **한 줄 30자 안팎**. "~라고 했어요/봤어요" 같은 대화 중계 금지, 내용 자체를 적는다. 발언자는 의견이 갈릴 때만 괄호. 예: `전부 가져와야 가치 (김선숙) / 샘플만이면 충분 (개발팀)`
- `questions`: 결론이 안 나 확인이 필요한 것. `next`: 정해진 다음 일정(날짜·회의·기한).
- 할 일로 뽑지 않은 작은 언급도 points나 questions에 남겨 **빠지는 내용이 없게** 한다. 녹취에 없는 내용은 쓰지 않는다.

요약(summary): 결정·중요 내용 2~4줄, 줄마다 `- `, 해요체 한 문장. 할 일로 뽑은 것은 반복하지 않는다.

## JSON 모양

```json
{"summary": "- …",
 "items": [{"text": "", "owner": "me|other|unclear", "who": "", "due": "", "dueDate": null, "time": null, "scope": "회사", "quote": "", "details": []}],
 "minutes": {"attendees": [], "topics": [{"topic": "", "points": [], "decisions": []}], "questions": [], "next": []}}
```

## Markdown 틀 (비어 있는 구획은 통째로 생략)

```markdown
# {제목}

일시: {YYYY-MM-DD}
참석: {attendees}

안건: 1. {topic} · 2. {topic} · …

## 요약
- {summary}

## 1. {topic}
- {point}
- **결정** {decision}

## 결정 사항
- {모든 decisions}

## 확인할 것
- {questions}

## 할 일
- [ ] {내 일} (나 · {due})
    - {details}
- [ ] {맡긴 일} ({who} · {due})

## 다음 일정
- {next}
```

## 점검 (저장 전에 스스로 확인)

- 내 일이 5개를 넘지 않는가. 넘으면 묶었는가
- `who`가 있는데 `unclear`로 둔 항목이 없는가
- 회의록에 "~라고 했어요" 꼴 문장이 남아 있지 않은가
- 할 일로 뽑지 않은 결정·숫자·날짜가 회의록 어딘가에 있는가
- 녹취에 없는 내용을 보탠 곳이 없는가
