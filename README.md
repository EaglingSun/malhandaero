# 말한대로

> 말만 하세요. 기억은 제가 할게요.

통화·회의 녹음, 말로 한 메모, 사진에서 **내가 챙길 일**을 뽑아 날짜별로 관리해 주는 개인 비서 앱입니다.
자기 PC에서 서버를 켜 두고, 휴대폰에서 접속해 씁니다. 설계는 [docs/DESIGN.md](docs/DESIGN.md)에 있습니다.

## 지금 되는 것

- 글 붙여넣기, 글 파일, 사진, **녹음 파일(m4a·mp3 등)**로 넣기 → 자동으로 챙길 것 뽑기 (음성 인식은 PC 안에서 돌아요)
- 회의·통화는 **회의록**(주제별 논의·결정·확인할 것)까지 정리. 복사하거나 .md로 받기
- 말하기 버튼 (브라우저 음성 인식이 되는 기기)
- 오늘 / 나중 / 안 함 고르기, 끝냄 체크, 직접 적기
- 날짜 이동과 주간 띠, 못 끝낸 일 자동 넘김, 날짜별 하루 정리
- 화자가 나뉜 글에서 "누가 나인가요?" 지정 후 다시 뽑기
- 넣은 것 목록: 원문 보기, 다시 뽑기, 지우기
- 가족 코드로 들어오기, 사람마다 분리된 목록
- 휴대폰 홈 화면 설치, 다른 앱의 "공유"로 받기 (HTTPS 주소에서)

## 아직 안 되는 것

- 더하기(장보기, 회의 후속): 설계와 자리만 있습니다.
- Claude Code 연결로 실제 뽑기: 부르는 방식은 시험했지만, 로그인된 PC에서 끝까지 돌려 본 적은 없습니다.
- 실제 휴대폰 화면에서의 확인: 서버 동작은 자동 시험으로 확인했고, 화면은 기기에서 직접 눌러 보며 확인해야 합니다.

## 설치와 실행

[INSTALL.md](INSTALL.md)를 따라 하면 됩니다. 요약하면 `git clone` → `install.bat` → `run.bat` → `http://localhost:8000` 입니다.
Mac은 `말한대로 처음 설치.command` 하나로 받기·설치·켜기를 한 번에 합니다. 켤 때마다 저장소의 업데이트를 알아서 받아 설치한 뒤 켭니다.

AI 연결은 세 가지입니다(`server/llm.py`). `.env`의 `MALHAN_AI`로 고정하거나, 비워 두면 되는 것을 고릅니다.

| 방식 | 조건 | 비용 |
|---|---|---|
| `claude` | 이 PC에 Claude Code가 설치·로그인되어 있음 | 본인 구독 안에서 사용 |
| `api` | `.env`에 `ANTHROPIC_API_KEY` | 쓴 만큼 과금 |
| `fake` | 없음 | 없음 (화면 확인용, 부정확) |

`claude` 방식은 각자 자기 PC에서 자기 로그인으로 쓰는 것을 전제로 합니다. 한 사람의 로그인으로 여러 사람이 쓰는 공용 서버로 돌리지 마세요.

## 휴대폰에서 쓰기 (집 밖 포함)

설치, 공유로 받기, 마이크는 **HTTPS 주소에서만** 동작합니다. 공유기 포트를 여는 대신 Tailscale을 권합니다.

1. 집 PC와 가족 휴대폰에 Tailscale을 설치하고 같은 계정(또는 초대)으로 연결합니다.
2. 집 PC에서 `tailscale serve --bg 8000`을 실행하면 `https://<PC이름>.<tailnet>.ts.net` 주소가 생깁니다.
3. 휴대폰 Chrome에서 그 주소를 열고, 이름과 가족 코드를 넣은 뒤 메뉴의 "홈 화면에 추가"를 누릅니다.
4. 이후 녹음 앱에서 "공유"를 누르면 목록에 말한대로가 나옵니다.

## 알아 둘 것

- 녹음 글과 사진은 챙길 것을 뽑는 단계에서 AI API로 전송됩니다. 회사 회의는 회사 보안 규정을 따르세요.
- 음성·사진 파일은 글로 바꾼 뒤 서버에서 지웁니다. 글 내용은 "넣은 것"에서 직접 지울 때까지 남습니다.
- 자료는 `data/` 폴더의 SQLite 파일 하나입니다. 이 폴더를 복사하면 백업입니다.

## 개발

```
pip install -r requirements-dev.txt
python -m pytest -q
```

| 위치 | 내용 |
|---|---|
| `server/app.py` | 주소(API)와 날짜별 조회 규칙 |
| `server/extract.py` | 추출 지시문, 응답 해석, 겹침 제거 |
| `server/transcript.py` | 화자 표기 해석, 긴 글 나누기 |
| `server/llm.py` | AI 호출 (모델을 바꿀 때 이 파일만) |
| `server/stt.py` | 음성 인식 (엔진을 바꿀 때 이 파일만) |
| `web/` | 화면 (빌드 단계 없음) |
| `docs/MINUTES_FORMAT.md` | 회의록·할 일 형식의 기준. `skills/meeting-minutes`는 같은 형식을 Claude Code에서 쓰는 스킬 |
| `server/updater.py` | 업데이트(git fast-forward) → 필요 시 재설치. 켜기 전(`tools/update.py`), 화면의 '업데이트', 새벽 자동 확인이 부른다 |
