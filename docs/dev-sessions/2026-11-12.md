### Lessons Learned
**시행착오** (실패 → 해결)
- 앞 세션의 자르기 스크립트(`slice.py`)는 좌표(`ROW_TOP = 4432` 등)가 옛 포스터 높이에 고정돼 있었다 → 단추 자리를 화면에서 읽어(`getBoundingClientRect`) 경계를 계산하게 새로 만들었다. 포스터를 고칠 때마다 좌표를 손으로 다시 찾지 않아도 된다.
- `tests/test_docs_sync.py::test_paths_in_docs_exist`가 이 PC에서 수정 전부터 실패했다. 문서에 적힌 `docs/img/poster/`가 커밋 제외 폴더라 새로 받은 저장소에는 없다(클라우드 세션에서는 그림을 만들어 폴더가 있었다) → `.gitignore`를 `docs/img/poster/*.png`로 좁히고 `.gitkeep`을 넣었다.
- 메인 대화의 이미지 읽기가 3장에서 막혔다(ctx_guard) → 눈 확인은 서브에이전트에 맡기고, 크기는 playwright로 재서 수치로 비교했다.
- `python -c` 안에 한글 · 백슬래시가 있으면 훅이 막는다 → 스크립트를 Write로 파일로 만들어 돌렸다.
- 저장소 수정이 가치 게이트(session_value_gate)에 세 번 막히고 네 번째 Edit 하나만 통과했다 → 그 한 줄을 되돌리고 가치 · 범위 블록을 낸 뒤 「승인」을 받고 다시 했다. 초안은 저장소 밖 복사본에서 만들어 아티팩트로 먼저 보였다.

**발견한 패턴** (재사용 가능)
- 포스터 문구를 정하는 동안은 저장소 파일을 고치지 않고 복사본 → 비공개 아티팩트 → 그림 순서로 돌리면 문구가 여러 번 바뀌어도 저장소가 깨끗하다. 정해진 뒤 한 번에 옮기고 `cmp`로 초안과 같은지 확인한다.
- 조각 그림은 「넓이 합 = 자른 범위」, 「빈 조각 색 1가지」, 「단추 조각 가장자리에 어두운 픽셀 0」을 코드로 확인하면 눈으로 보지 않아도 빠짐 · 겹침 · 단추 잘림을 잡는다.
