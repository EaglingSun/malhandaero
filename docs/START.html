말한대로 · 시작 안내

말한대로 셋업 가이드

PC는 켜 두는 서버, 쓰는 건 폰. 아래 5단계(15분)만 따라 하면 쓸 수 있어요. 「더 자세히」는 막혔을 때만 보세요.

단계 어디서 시간
① PC에 설치 (Claude 연동은 자동) PC 5분
② 구글 캘린더 연결 (선택) PC 브라우저 1분
③ 폰에 앱으로 설치 폰 Chrome 3분
④ 할 일 넣어 보기 폰 1분
⑤ 회사 밖에서도 쓰기 (선택) PC + 폰 5분

① PC에 설치 — Claude 연동은 자동이에요

  1. 설치 파일을 받아 실행해요.
  2. Windows: setup-windows.bat 더블클릭 — Git·Python·Claude Code가 없으면 알아서 깔아요. 설치 위치는 C:\Users\이름\malhandaero
  3. Mac: setup-mac.command 우클릭 → 열기 — Python은 python.org에서 먼저. 설치 파일을 둔 곳의 malhandaero 폴더에 들어가요
  4. 검은 창에서 로그인 코드를 하나 정해요 (예: 1234). 폰에서 들어올 때 한 번 쓰고, 잊으면 .env의 MALHAN_FAMILY_CODE= 줄에 있어요.
  5. 2~5분 뒤 서버가 켜지고 PC 브라우저가 http://localhost:8000으로 열려요. Windows 방화벽 창이 뜨면 「액세스 허용」.

됐는지 확인: 검은 창에 AI Claude Code가 보이면 연결된 거예요. AI 없음이면 터미널에서 claude를 한 번 실행해 로그인하고, 「말한대로 켜기」로 다시 켜요.

Claude 구독(Pro 이상)이 없어도 쓸 수 있어요. 녹음과 글에서 할 일을 자동으로 뽑는 기능만 쓸 수 없어요. 직접 적기·캘린더·하루 마무리는 똑같이 쓸 수 있어요.

다음부터는 바탕 화면 「말한대로 켜기」(Mac은 start.command)를 더블클릭해요. PC를 켤 때 자동으로 켜지게 하려면 자동 시작을 보세요.

② 구글 캘린더 연결 — PC 브라우저에서 1분 (선택)

연결하면 날짜 정한 할 일이 캘린더에 올라가고, 캘린더의 회의를 「할 일로」 가져올 수 있어요.

  1. 방금 열린 PC 브라우저(http://localhost:8000)에서 이름과 코드를 넣고 들어가요.
  2. 맨 아래 「캘린더 연결」 → 「구글 계정으로 연결」 → 구글 로그인.
  3. "확인되지 않은 앱" 화면이 나오면 고급 → 말한대로(으)로 이동 → 허용.
  4. 돌아오면 「할 일을 올릴 캘린더」에 기본 캘린더가 잡혀 있어요. 다른 캘린더를 쓰려면 골라요.

됐는지 확인: 「오늘」 화면 위에 「캘린더 일정」이 떠요. 폰에서도 보여요. 구글 연결 버튼은 PC의 localhost에서만 눌러요. 네이버 캘린더는 캘린더 자세히.

③ 폰에 앱으로 설치 — 폰 Chrome에서 3분

폰과 PC가 같은 와이파이여야 해요.

  1. 검은 창에 있는 폰에서 열 주소(http://10.x.x.x:8000)를 폰 Chrome 주소창에 입력하고, 이름과 로그인 코드를 넣어 들어가요. (네이버·삼성 브라우저로 열렸으면 화면의 「Chrome으로 열기」를 눌러요)
  2. 위에 뜨는 띠 「먼저 앱으로 설치하면…」의 설치하기를 눌러요.
  3. 「설치가 안 돼요 (http 주소라서)」를 펼쳐 주소 복사를 눌러요. 새 탭 주소창에 chrome://flags/#unsafely-treat-insecure-origin-as-secure를 입력하고, 입력칸에 복사한 주소를 붙여넣어요. 옆의 선택을 Enabled로 바꾸고 Relaunch를 눌러요. (한 번만 하면 돼요. PC 주소가 바뀌면 다시 해요)
  4. Chrome이 다시 열리면 「지금 설치」를 눌러요(또는 Chrome 메뉴 ⋮ → 「설치 및 바로가기 만들기」).

됐는지 확인: 홈 화면에 초록 아이콘이 생기고, 녹음 앱의 공유 목록에 「말한대로」가 나와요. 말하기 버튼도 쓸 수 있어요.

플래그에 주소 넣고 Enabled 다시 열면 「설치」

⑤의 https 주소로 들어가면 위 3번은 건너뛰어요.

④ 할 일 넣어 보기 — 1분

홈 화면 아이콘으로 열어서:

해 보기 결과
+ → 말하기 "내일 무당이한테 견적 보내기" 내일 할 일로 들어가요
녹음 앱에서 녹음 하나를 골라 텍스트 변환, 공유, 말한대로 순서로 누르기 할 일 + 회의록이 「넣은 것」에 와요 (10~30초)
+ → 글 붙여넣기 에 메모 한 줄 챙길 것만 뽑혀요. 남의 일("슈구리 씨가 해 주기로")은 빠지는 게 정상
+ → 직접 적기 AI 없이 바로 오늘 할 일

할 일마다 오늘 · 나중 · 안 함 중 하나만 누르면 돼요. 못 끝낸 일은 다음 날로 넘어가요. 하루를 마칠 땐 「오늘은 여기까지」를 누르고, 지난날은 「달력」에서 봐요.

⑤ 회사 밖에서도 쓰기 — Tailscale, 5분 (선택)

③은 같은 와이파이에서만 돼요. 퇴근 뒤나 출장지에서도 쓰려면 Tailscale(무료)로 PC와 폰을 연결해요. 내 기기끼리만 연결돼요.

  1. tailscale.com/download에서 PC와 폰에 설치하고 같은 계정(구글 등)으로 로그인. Windows는 winget install --id Tailscale.Tailscale -e, Mac은 App Store.
  2. 처음 한 번: login.tailscale.com/admin/dns에서 MagicDNS와 HTTPS Certificates를 켜요.
  3. PC에서 말한대로를 껐다 켜요. Tailscale이 켜져 있으면 검은 창에 https://내PC이름.○○○.ts.net 주소가 떠요.
  4. 폰(Tailscale 켠 상태)에서 그 주소로 들어가 「앱으로 설치하기」. https라 플래그 없이 바로 설치돼요.

됐는지 확인: 와이파이를 끄고 LTE로 그 주소가 열리면 잘 된 거예요.

막히면 앱 맨 아래 「휴대폰에서 쓰기」(폰에서는 「앱으로 설치하기」)를 열고 「다른 사람과 같이 쓰기」에서 도우미 글 복사를 눌러, 복사한 글을 Claude나 ChatGPT에 붙여넣어요. 팀원·가족 폰은 같이 쓸 사람 폰 연결하기를 보세요.

더 자세히

밖에서 쓸 때 지킬 것

  • PC가 켜져 있고 말한대로가 떠 있어야 해요. 회사 PC를 퇴근 때 끄면 그동안은 안 열려요. 늘 켜 둘 수 있는 컴퓨터에 설치하거나, 「자동 시작」을 등록하고 끄지 마세요.
  • Mac은 덮개를 닫으면 잠들어요. 시스템 설정 → 배터리 → 전원 어댑터에서 "디스플레이가 꺼져 있을 때 자동으로 잠자기 방지"를 켜요. Windows는 설정 → 시스템 → 전원의 절전을 "안 함"으로 해요.
  • 밖에서 쓰는 주소를 만들지 않으려면 tools\run.bat --local(Mac tools/run.sh --local)로 켜요. 전에 열어 둔 주소도 같이 닫혀요(이 PC의 Tailscale serve 설정이 모두 지워져요. 말한대로만 쓰고 있다면 상관없어요).

같이 쓸 사람 폰 연결하기

팀원이나 가족과 같이 쓸 수 있어요. 목록은 사람마다 따로예요.

같은 와이파이에서만 쓸 사람은 Tailscale 없이: 앱의 「휴대폰에서 쓰기 → 다른 사람과 같이 쓰기 → 같은 와이파이용 QR」을 찍으면 이름만 정하고 들어와요.

밖에서도 쓰게 하려면 그 사람 폰이 내 Tailscale 네트워크에 들어와야 해요. 둘 중 하나:

  • 내 계정을 같이 써도 되는 사람: 그 폰에 Tailscale 앱을 깔고 내 계정으로 로그인. 가장 간단해요.
  • 따로 계정을 쓰는 사람 — 초대: login.tailscale.com/admin/users → Invite external users → 초대 링크를 카카오톡 등으로 보내요. 받은 사람은 링크를 열어 본인 계정으로 수락 → 폰에 Tailscale 설치 → 그 계정으로 로그인 → 연결 켜기. 그 사람 폰의 Tailscale 기기 목록에 내 PC 이름이 보이면 된 거예요.

그다음 앱의 「다른 사람과 같이 쓰기 → 초대 QR」을 찍으면 이름만 정하고 들어와요. 로그인 코드는 「들어올 때 쓰는 코드 바꾸기」에서 바꿀 수 있어요.

주의: 한 사람의 Claude Code 로그인으로 여러 명이 쓰는 공용 서버는 구독 약관에 맞지 않아요. 여럿이 같이 쓸 땐 AI가 PC 주인의 구독을 쓴다는 점을 알고, 팀이면 각자 PC에 설치하는 쪽을 권해요.

캘린더 자세히

  • 기본은 시각을 정한 일만 캘린더에 넣어요(캘린더가 복잡해지지 않게). 「캘린더에 자동으로 넣을 일」에서 "날짜가 정해진 모든 일"로 바꿀 수 있어요.
  • 할 일을 고치면 캘린더도 바뀌고, 나중으로 미루거나 지우면 캘린더에서도 빠져요.
  • 「할 일로」 가져온 일을 고치거나 지워도 캘린더의 일정은 바뀌지 않아요. 안 볼 일정은 「숨기기」를 눌러요.
  • 「일정을 가져올 캘린더」에서 공유 캘린더 등 다른 캘린더를 고를 수 있어요(올리는 캘린더는 그대로).
  • 연결 정보(네이버 비밀번호, 구글 토큰)는 이 PC의 data/에만 저장돼요. 「연결 끊기」를 해도 캘린더의 일정은 그대로 있고, 같은 캘린더로 다시 연결하면 중복 없이 이어져요.

네이버 캘린더 (2분): 네이버 로그인 → 내정보 → 보안설정 → 2단계 인증 켜기 → 같은 화면 애플리케이션 비밀번호 관리에서 하나 만들기(종류 "직접 입력", 이름 "말한대로") → 앱의 「캘린더 연결 → 네이버」에 아이디와 그 비밀번호.

본인 구글 클라이언트로 쓰기 (선택, 10분): 내장 등록은 PC의 localhost에서만 연결을 받아요. 폰(https 주소)에서도 연결 버튼을 누르고 싶으면 본인 등록을 만들어요.

  1. console.cloud.google.com에서 프로젝트를 만들어요.
  2. API 및 서비스 → 라이브러리에서 "Google Calendar API"를 사용으로 바꿔요.
  3. OAuth 동의 화면: 외부, 앱 이름 "말한대로", 앱 게시로 프로덕션.
  4. 사용자 인증 정보 → OAuth 클라이언트 ID(웹 애플리케이션)를 만들어요.
  5. 승인된 리디렉션 URI에 http://localhost:8000/api/calendar/google/callback과 https://내PC이름.○○○.ts.net/api/calendar/google/callback을 넣어요.
  6. .env에 MALHAN_GOOGLE_CLIENT_ID=…, MALHAN_GOOGLE_CLIENT_SECRET=…을 적고 다시 켜요.

같은 와이파이의 http://10.x… 주소로는 구글이 연결을 받지 않아요.

PC에 로그인하면 알아서 켜지게

  • Windows: 바탕 화면 「말한대로 자동 시작」 더블클릭. 로그인하면 최소화된 창으로 켜져요. 해제는 명령 프롬프트에서 tools\autostart.bat remove.
  • Mac: autostart-on.command 더블클릭. 창 없이 돌고 출력은 data/server.log. 해제는 autostart-off.command.

자동 시작은 PC 브라우저를 열지 않아요. 켤 때 브라우저가 열리는 게 싫으면 .env에 MALHAN_OPEN_BROWSER=0.

업데이트

  • 새 버전은 알아서 와요. 켤 때와 새벽 4시에 받아요. 쓰는 중에 「새 버전이 있어요 · 지금 적용」 띠가 뜨면 누르거나, 화면 맨 아래 「업데이트」를 눌러요.
  • 기록(data/)과 설정(.env)은 바뀌지 않아요. 인터넷이 안 되면 지금 버전으로 켜져요.
  • 안 받으려면 tools\run.bat --no-update, 아예 끄려면 .env에 MALHAN_AUTO_UPDATE=0. 보자마자 바로 적용하게 하려면 MALHAN_AUTO_UPDATE=now.
  • 폴더 안 파일을 손으로 고치면 업데이트가 건너뛰어요(덮어쓰지 않음). 켤 때 "직접 고친 파일이 있어서…"가 나오면 그 뜻이에요.
  • 필요한 기능은 게시글 댓글로 알려 주세요. 고쳐서 올리면 모두의 앱에 새 버전으로 들어가요.

PC가 두 대일 때

PC 두 대(집·회사)면 각 .env에 MALHAN_LABEL=집 / MALHAN_LABEL=회사 → 폰에 「말한대로 · 집」「말한대로 · 회사」 두 앱으로 나란히 깔려요.
