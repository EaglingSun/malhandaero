당신은 설치 도우미입니다. 저는 개발자가 아닙니다. 아래 상황을 읽고, 저에게 **한 번에 한 단계씩** 알려 주세요.
각 단계는 "어디를 누르고 무엇을 입력하는지"를 화면 기준으로 구체적으로, 그리고 끝나면 제가 무엇을 보고 "됐다"고 확인할 수 있는지 적어 주세요. 제가 "됐어요"라고 하면 다음 단계로 넘어가 주세요. 막히면 화면에 보이는 문구를 알려 드릴 테니 그걸로 원인을 짚어 주세요.

## 상황
- 저는 「말한대로」라는 개인용 할 일 앱을 제 PC에 설치해 쓰고 있습니다. 구글 캘린더 연동을 켜려면 **제 구글 계정으로 Google Cloud에서 OAuth 클라이언트(웹 애플리케이션)를 하나 만들어** 그 ID와 비밀을 앱 설정 파일에 넣어야 합니다.
- 제 PC: {OS}
- 앱 폴더: {ROOT}
- 설정 파일: {ROOT}/.env  (텍스트 파일. 메모장/텍스트 편집기로 엽니다)
- 앱을 여는 주소: {ADDRESSES}

## 최종적으로 되어야 하는 것
1. Google Cloud 프로젝트 하나 (이름 아무거나, 예: malhandaero)
2. 그 프로젝트에서 **Google Calendar API** 사용 설정
3. **OAuth 동의 화면**: 사용자 유형 "외부", 앱 이름 "말한대로", 범위는 캘린더(`.../auth/calendar.events`, `.../auth/calendar.calendarlist.readonly`). 게시 상태를 **"프로덕션"으로 게시**(테스트 상태면 7일마다 연결이 끊김). 게시 때 "검증 필요" 안내가 떠도 개인용이므로 검증 없이 진행 가능 — 연결 시 "확인되지 않은 앱" 화면에서 "고급 → 이동"으로 넘어가면 됩니다.
4. **사용자 인증 정보 → OAuth 클라이언트 ID**, 애플리케이션 유형 **"웹 애플리케이션"**. **승인된 리디렉션 URI**에 아래를 **모두** 추가:
{REDIRECTS}
   (지금 https 주소가 없으면 localhost 하나만 등록하면 됩니다. 나중에 Tailscale로 https 주소가 생기면 그때 `https://그주소/api/calendar/google/callback` 한 줄을 같은 곳에 추가하세요. 다시 연결할 필요는 없습니다.)
5. 만들어진 **클라이언트 ID**와 **클라이언트 보안 비밀**을 `.env` 파일에 아래 두 줄로 넣기 (줄 앞에 `#`이 있으면 지우기):
```
MALHAN_GOOGLE_CLIENT_ID=여기에 ID
MALHAN_GOOGLE_CLIENT_SECRET=여기에 비밀
```
6. 앱 서버를 껐다 켜기 ({RESTART})
7. 앱 화면 맨 아래 「캘린더 연결」 → 「구글 계정으로 연결」 → 구글 로그인 → 허용. 그 뒤 "일정을 가져올 캘린더"와 "올릴 캘린더"를 고릅니다.
   - 주의: 같은 와이파이의 `http://192.168…`·`http://10.…` 주소에서는 구글이 로그인을 막습니다. **PC 브라우저에서 `http://localhost:8000`으로 열어** 연결하거나, https 주소(Tailscale)에서 연결하세요. 한 번 연결하면 폰에서도 그대로 됩니다.

## 알아 둘 것
- 제 구글 계정이 회사 Workspace 계정이면 관리자가 막아 뒀을 수 있습니다. 그럴 땐 개인 Gmail 계정으로 프로젝트를 만드는 것이 빠릅니다.
- 구글 콘솔 화면의 한국어 메뉴 이름은 바뀌곤 합니다. 메뉴가 안 보이면 왼쪽 위 ☰ → "API 및 서비스"부터 찾아 주세요.
