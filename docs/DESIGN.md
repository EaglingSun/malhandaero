# 말한대로 설계서

> 말만 하세요. 기억은 제가 할게요.

녹음(통화, 회의, 혼잣말)과 사진에서 **내가 챙길 일**을 뽑아 하루 단위로 관리해 주는 개인 비서 앱. 설치·사용은 `docs/START.md`, 코드 구조와 결정은 `docs/ARCHITECTURE.md`, 남은 일은 `docs/HANDOFF.md`.
사람이 하는 일은 "말하기, 고르기, 체크"뿐이고 기록·정리·이월은 앱이 한다.

## 1. 홍보에서 한 약속과 설계 대응

홍보 페이지(`docs/POSTER.html`)에 쓴 문장은 곧 요구사항이다. 각 문장이 어떤 기능으로 지켜지는지 추적한다. 포스터 문구를 바꾸면 이 표도 맞춘다. (1차 배포 11/10 기준)

| 약속 (포스터 문구) | 지키는 기능 | 상태 |
|---|---|---|
| 말만 하세요 | 넣기 시트의 「말하기」(브라우저 음성 인식, 안 되면 녹음해 서버로) | 됨 — 앱으로 설치한 뒤(또는 https)에서 |
| 녹음 앱에서 「공유」 한 번 | 폰 녹음 앱의 공유 목록에 말한대로 (PWA share target). 텍스트 변환본이 기본, 음성 파일도 됨(whisper) | 됨 |
| 챙길 일은 할 일로 · 회의는 회의록으로 | 받는 즉시 자동 추출. 통화·회의면 회의록까지. 남의 일은 「내 일로 가져오기」 | 됨 |
| 다 이 앱 하나로 관리해요 (캘린더 일정 · 회의에서 맡은 일 · 통화로 한 약속 · 머릿속 할 일) | 이 표의 공유 · 자동 추출 · 말하기 · 캘린더 줄이 지킨다. 메신저 부탁은 말하거나 사진을 찍어 넣는다 | 됨 |
| 말하거나, 붙이거나, 찍거나 | 넣기 시트: 말하기 · 글 붙여넣기 · 사진 찍기 · 파일 넣기 · 직접 적기 | 됨 |
| 일정은 캘린더로 · 오늘 일정이 할 일 위에 | 구글(내장 클라이언트, PC localhost에서 한 번)·네이버. 올리기 + 가져오기 | 됨 |
| 「오늘은 여기까지」, 씨앗이 자라요 | 정리 글, 못 끝낸 일 자동 이월, 오늘 한 줄(기분·문구), 달력 | 됨 |
| 내 상황에 맞게, 세 가지로 써요 (늘 켜 두는 서버 · 내 업무 PC · Claude 없이) | 늘 켜 두는 컴퓨터 + Tailscale(START ⑤)이면 밖에서도, ①~④만 하면 같은 와이파이에서 PC가 켜진 동안, AI가 없으면(`llm.mode()`가 `none`) 직접 적기 · 캘린더 · 하루 마무리 | 됨 |
| 내 PC가 서버 · 내 PC에만 | 각자 PC의 서버와 `data/`. AI로 가는 때는 8장 | 됨 |
| 설치는 파일 하나로 시작해요 | `setup-windows.bat` / `setup-mac.command` → 바탕 화면 바로가기, 폰은 Chrome 예외 등록 후 설치 | 됨 |
| 구독 중인 Claude로, API 키 없이 | 이 PC의 Claude Code CLI를 부른다. 없으면 AI 없이 할 일 앱으로 | 됨 — Pro 이상 구독 전제 |
| 새 기능은 「업데이트」 버튼으로 | 켤 때·새벽 4시 자동, 한 시간마다 확인해 「지금 적용」 띠 | 됨 |
| (포스터에 없음) 오늘 · 나중 · 안 함 | 하나만 누르면 끝. `README.md` 「되는 것」에 있다 | 됨 |
| (포스터에 없음) 개인/회사 | 할 일에 개인/회사 표시. PC 두 대면 `MALHAN_LABEL`로 폰에 두 앱 | 됨 |
| 필요한 것만 골라 더하기 | 더하기(애드온) | **공모 이후**. 홍보에서는 뺐다 |
| 다양한 AI 연결 | codex / api / gpt / gemini / ollama / openai 모드 | 코드만, 다음 버전에서 안내 |

## 2. 입력 종류

| 종류 | 들어오는 형태 | 처리 |
|---|---|---|
| 통화 녹음 | 폰이 만든 글 파일(공유) 또는 음성 파일 | 화자 2명. "나"를 한 번 지정하면 내 약속만 추출 |
| 회의 녹음 | 글 파일(화자 분리 포함) 또는 음성 파일 | 화자 여러 명. "나" 지정. 길면 나눠서 추출 |
| 화자 분리된 기록 | `화자 1 00:12` 같은 표기가 있는 글 | 표기를 해석해 화자 목록을 만든다 |
| 녹음 파일 | m4a, mp3, wav, webm 등 | 서버에서 글로 변환(STT) 후 추출 |
| 말로 하는 메모 | 앱의 말하기 버튼 | 전부 내 말이므로 문장마다 할 일로 본다 |
| 사진 | 안내문, 손 메모, 칠판, 화면 캡처, 영수증 | AI가 사진 내용을 글로 옮긴 뒤 같은 추출 과정을 탄다. 사진은 옮긴 뒤 지운다 |
| 직접 입력 | 한 줄 추가 | 추출 없이 바로 목록에 넣는다 |

## 3. 처리 흐름

```
받기 ─→ 글로 바꾸기 ─→ 화자 해석 ─→ 추출 ─→ 겹침 제거 ─→ "새로 적어 둔 것"
(공유/말하기/     (음성: 음성 인식   (나 지정)    (AI)     (기존 목록과 비교)
 사진/파일)       사진: AI가 읽기)
```

입력 한 건의 상태 값은 `docs/ARCHITECTURE.md` 1절.

- **글로 바꾸기**: 기본은 이 PC의 로컬 음성 인식(faster-whisper)이라 녹음이 밖으로 나가지 않는다. whisper가 없고 Gemini 키가 있으면 Gemini가 듣는다(8장).
  말하기 버튼은 브라우저 음성 인식이 되면 그것을 먼저 쓰고, 안 되면 녹음해서 서버로 보낸다.
  안드로이드는 말을 쉬면 인식을 끊으므로 사람이 끝내기 전엔 다시 켜서 이어 듣고(최대 1시간, 50분부터 남은 시간 안내),
  화면이 바뀌거나 전화가 오면 그때까지 들은 말을 바로 보낸다. 들은 말은 폰에 임시로 두었다가 앱이 꺼졌으면 다음에 열 때 보낸다.
- **사진 읽기**: 글로 바꾸기 단계의 다른 길이다. 사진을 AI에 보내 보이는 글을 옮겨 적게 하고, 그 뒤는 녹음과 같다.
  큰 사진은 서버에서 줄여서 보낸다.
- **화자 해석**: 화자 표기가 2명 이상이면 "누가 나인가요?"를 한 번 묻는다. 답하기 전에도 추출은 하되
  "내 일로 보이는 것"만 뽑고, 지정하면 다시 추출한다.
- **추출 규칙**: 내 일은 내가 하겠다고 한 일, 내가 부탁받아 맡은 일, 잊지 않으려고 말한 일. 남의 일은 따로 담아 두고(「내 일로 가져오기」), 끝난 일·잡담은 뺀다.
  항목마다 근거 문장, 기한 표현, 기한 날짜, 개인/회사를 붙인다.
- **겹침 제거**: 아직 열려 있는 항목과 문장이 거의 같으면 새로 만들지 않는다.
- **쓸수록 맞춰지기**: "안 함"으로 넘긴 최근 항목을 추출 지시에 반례로 넣는다.

## 4. 날짜 관리

항목은 "날짜에 붙는다". 하루치 화면은 그날에 붙은 항목을 보여 주는 뷰다.

| 필드 | 뜻 |
|---|---|
| `status` | `new`(새로 적어 둠) `todo`(하기로 함) `later`(나중) `skipped`(안 함) `done`(끝냄) `other`(남의 일 — 날짜 화면에는 안 나온다) |
| `plan_date` | 하기로 한 날. `todo`·`done`에 있음(끝낸 일은 끝낸 날 화면에 남기려고) |
| `due_date` | 녹음에 나온 기한 |
| `done_at` | 끝낸 날. 지난 날짜 화면에서 체크하면 그날, 미래 날짜면 오늘. 체크를 풀면 그 화면의 날짜로 `todo` |

어느 날짜 D의 화면(T = 오늘):

- **하기로 한 일**: `todo`이고 `plan_date = D`. D가 오늘이면 `plan_date < T`인 것도 함께 보이고 "N일 넘어옴"을 붙인다.
- **끝낸 일**: `done`이고 `done_at = D`
- **기한인 일**: `due_date = D`인데 아직 `new`/`later`인 것 (놓치지 않게 알려 줌)
- **새로 적어 둔 것**: 오늘 화면에서만 보인다.

이월은 일괄 작업이 아니라 **조회 규칙**이다. 지난 날짜에 남은 `todo`는 오늘 화면에 저절로 나타난다.
그래서 며칠 앱을 안 열어도 어긋나지 않고, 지난 날짜 화면에는 "그날 못 끝낸 일"이 그대로 남는다.

- **달력 띠**: 일주일 단위로 날짜별 남은 일·끝낸 일 개수를 보여 주고, 눌러서 이동한다.
- **미리 잡기**: 항목을 "오늘" 대신 다른 날짜로 보낼 수 있다(`plan_date` 지정).
- **하루 정리**: 날짜별로 한 번 저장한다(`day_logs`). 지난 날짜를 열면 그날의 정리가 보인다.

## 5. 입력(녹음) 관리

- 입력은 받은 날짜별로 "넣은 것" 목록에 쌓인다. 종류, 제목, 뽑힌 항목 수, 상태가 보인다.
- 입력을 열면 글 내용, 화자 목록, 여기서 나온 항목이 보인다. 항목의 근거 문장은 원문으로 이어진다.
- 할 수 있는 일: "나" 다시 지정, 다시 뽑기, 지우기.
- **보관 원칙**: 음성 파일은 글로 바꾼 뒤 바로 지운다(기본값). 글 내용은 본인이 지울 때까지 둔다.
  입력을 지워도 이미 고른 항목은 남는다.

```
│ 하루 마무리 [오늘은 여기까지]   │  기분·문구·한 줄(켠 사람만)
│ 휴대폰에서 쓰기 / 캘린더 연결   │  바닥 링크로 펼침 (폰에선 「앱으로 설치하기」)
├───────────────────────────┤
│  오늘 │ 나중 │ 넣은 것 │ 달력  │  아래 탭 4개          (+) 떠 있는 단추
└───────────────────────────┘
```

- **+ 단추 → 넣기 시트**: 「직접 적기」(AI 없이) / 「AI가 대신 적어요」 말하기 · 글 붙여넣기 · 사진 찍기 · 파일 넣기. AI가 없으면 AI 칸은 쉬고 안내만.
- **달력 탭**: 월 달력에 날짜별 끝낸·남은 개수와 그날 기분, 식물이 자라는 활용 카드(🫘→🌱→🌿→🌷→🌳), 맨 아래에 공모 게시글 「좋아요 누르러 가기」 배너(기본 주소는 `server/app.py`의 `POST_URL_DEFAULT`, `.env`의 `MALHAN_POST_URL`로 바꾸고 빈 값이면 숨김).
- **PC(900px 이상)**: 가운데 640px 한 열, 탭은 떠 있는 둥근 막대, + 단추는 열 오른쪽 위, 넣기 시트는 위쪽 가운데 창.
- 설치된 앱(standalone)에서는 「휴대폰에서 쓰기」가 숨고, 폰 브라우저(설치 전)에서는 맨 위에 「먼저 앱으로 설치하세요」 띠.

## 7. 구조

코드 구성 · 데이터 모델 · 바깥 연결 · 켜기와 업데이트는 `docs/ARCHITECTURE.md`에 있다. 여기에는 그렇게 정한 이유만 남긴다.

- **왜 서버에 저장하나**: 폰에서 말하고 PC에서 고르는 흐름이 되려면 기기 간에 같은 목록이 보여야 한다.
- **사람 구분**: 로그인 코드(서버 `.env`의 `MALHAN_FAMILY_CODE`)와 이름으로 들어온다. 사람마다 목록이 완전히 분리된다. 설치 때 본인이 정하고 앱에서 바꿀 수 있다.

## 8. 개인정보와 회사 정보

- 기록은 이 PC의 `data/`에만 저장한다. **AI로 가는 때는 할 일을 뽑을 때와 하루 마무리 글을 쓸 때 둘이다**(기본은 이 PC의 Claude Code). 무엇이 가는지는 `docs/ARCHITECTURE.md` D-14. 통화에는 상대방의 말이 들어 있으므로 이 점을 `README.md`와 `docs/START.md`의 「알아 둘 것」에 밝힌다.
- 회사 회의는 회사 보안 규정을 따른다.
- 음성·사진 원본은 글로 바꾼 뒤 지운다.
- 아직 없는 것(계획): 앱 화면 안의 같은 안내, 민감한 사진(주민등록증·카드)을 넣지 말라는 안내, 사내 배포판에서 사내 허용 모델만 쓰게 막는 설정.

## 10. 측정할 것 (공모 글의 수치)

- 할 일을 옮겨 적는 시간: 사용 전 → 사용 후
- 추출 정확도: 뽑힌 것 중 "안 함"으로 넘긴 비율, 빠뜨려서 직접 추가한 건수
- 녹음을 넣은 뒤 목록에 뜰 때까지 걸린 시간

## 11. 더하기(애드온) — 계획. 아직 만들지 않았다

본체는 "챙길 일"만 안다. 주제별 기능은 **더하기**로 붙이고, 사람마다 켜고 끈다.
배포한 뒤에도 폴더 하나를 추가하면 새 더하기가 붙도록 한다.

### 더하기가 할 수 있는 일 (네 가지 접점)

| 접점 | 뜻 | 예 (장보기) |
|---|---|---|
| 읽기 | 들어온 글(녹음·사진)에서 자기 주제의 자료를 뽑는다 | 영수증 사진에서 재료, 수량, 산 날짜 |
| 기록 | 자기 자료를 `records`에 쌓는다 | 냉장고 재료 목록 |
| 화면 | 탭 하나를 가진다 | "냉장고" 탭 |
| 할 일 연결 | 본체의 할 일 목록에 항목을 넣는다 | "시금치 내일까지 쓰기"가 오늘 목록에 뜸 |

본체가 더하기에게 주는 것은 글 내용과 날짜뿐이고, 더하기가 본체에 넣을 수 있는 것은 할 일 후보뿐이다.
더하기끼리는 서로 모른다. 그래서 하나를 꺼도 나머지와 본체는 그대로 돈다.

### 구성

```
addons/
  groceries/
    addon.py     # 아래 인터페이스 구현
    panel.js     # 탭 화면
  meeting_followup/
    addon.py
    panel.js
```

```python
class Addon:
    id = "groceries"
    name = "장보기"
    blurb = "영수증을 찍으면 재료를 정리하고, 먹을 때를 챙겨 드려요."

    def wants(self, input) -> bool:
        """이 입력을 볼지. (예: 사진이고 영수증으로 보이면)"""

    def read(self, text, ctx) -> list[Record]:
        """글에서 자기 자료를 뽑는다. AI 호출은 본체의 llm을 쓴다."""

    def todos(self, records, today) -> list[Candidate]:
        """기록을 보고 본체에 넣을 할 일 후보를 만든다. 매일 한 번 불린다."""

    def view(self, records, today) -> dict:
        """탭 화면에 줄 자료."""
```

할 일에는 `addon`과 `record_id`가 붙어, 어느 더하기의 어떤 기록에서 왔는지 따라갈 수 있다.
할 일을 끝내면 더하기에 알려 준다(예: "두부 쓰기"를 끝내면 냉장고 목록에서 두부가 빠진다).

### 첫 더하기 두 개

**장보기 (생활)**
- 넣기: 영수증 사진, 또는 "오늘 두부랑 시금치 샀어"라고 말하기
- 정리: 재료별로 산 날짜와 "먹기 좋은 기한"을 붙인다
- 챙김: 기한이 가까운 재료를 오늘 할 일에 올린다
- 추천: 지금 있는 재료로 만들 수 있는 음식을 몇 가지 제안한다
- 주의: 기한은 재료 종류에 따른 **어림값**이다. 영수증에는 유통기한이 없으므로 화면에 "어림"이라고 표시하고,
  포장에 적힌 날짜를 직접 고칠 수 있게 한다. 포장의 날짜가 항상 우선이다.

**회의 후속 (업무)**
- 넣기: 회의 녹음 (본체가 받은 것을 같이 본다)
- 정리: 내 일뿐 아니라 **남이 하기로 한 일**도 뽑아 "받을 것" 목록으로 둔다
- 챙김: 기한이 지난 "받을 것"은 "확인하기" 할 일로 오늘 목록에 올린다
- 공유: 회의별 결정 사항과 담당자 표를 글로 만들어 복사한다
- 맨 처음 풀려던 문제(회의 액션이 흩어지고 추적이 안 됨)에 대한 답이 이 더하기다.
