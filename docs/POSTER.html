오늘나중넣은 것달력

내 PC 하나면 돼요

  • 내 PC가 서버PC를 켜 두는 동안 폰에서 써요. 서버를 따로 빌리지 않아요.
  • 내 PC에만기록은 내 PC에만 저장돼요. AI에는 할 일을 뽑을 때와 하루 마무리 글을 쓸 때만 글을 보내요.
  • 구독 중인 Claude로API 키 없이 구독(Pro 이상) 사용량으로 써요. 구독이 없으면 할 일 앱으로 써요.
  • 새 버전은 알아서PC를 켤 때와 새벽에 새 버전을 받아요. 기록과 설정은 바뀌지 않아요.
준비된 PC 기준 15분 · 5단계

설치는 파일 하나로 시작해요

  1. PC에 설치아래 파일을 실행하고 로그인 코드를 정해요. Claude Code는 처음 한 번 로그인해요.
  2. 구글 캘린더 연결열린 PC 브라우저에서 「캘린더 연결 → 구글 계정으로」. 경고가 뜨면 고급 → 허용. 선택.
  3. 폰에 앱으로 설치같은 와이파이에서 폰 Chrome으로 주소를 열어요. Chrome에 주소를 한 번 등록하면 설치돼요. 홈 화면에 생겨요.
  4. 할 일 넣어 보기+ 단추로 말하거나, 녹음 앱에서 말한대로로 공유해요.
  5. 집 밖에서도 쓰기Tailscale로 PC와 폰을 연결해요. 5분, 선택.
Windows 설치 파일 Mac 설치 파일 시작 안내 Android 폰 + Chrome 기준 · 처음 쓰는 PC는 프로그램 설치로 더 걸려요
