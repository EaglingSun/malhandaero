말한대로 개인정보처리방침

시행일 2026년 11월 10일

말한대로는 사용자가 자기 PC에 직접 설치해 쓰는 할 일 앱입니다. 통화·회의 녹음, 말로 한 메모, 사진에서 내가 챙길 일을 뽑아 날짜별로 정리합니다. PC 주인이 자기 PC에서 실행하며, 같은 와이파이 또는 같은 Tailscale 네트워크에 들어온 기기(본인과 초대한 사람)에서만 열립니다.

1. 다루는 정보

  • 들어올 때 적은 이름
  • 넣은 글, 녹음을 글로 바꾼 내용, 사진에서 읽은 내용 (사진과 녹음 파일은 글로 옮긴 뒤 지웁니다)
  • 뽑힌 할 일과 그 날짜·시각, 하루 정리
  • 캘린더를 연결한 경우: 네이버 아이디와 애플리케이션 비밀번호, 또는 구글 연결 값(리프레시 토큰)

2. 보관 장소

모든 정보는 말한대로를 실행하는 PC의 data/ 폴더에만 저장됩니다. 따로 운영하는 바깥 서버는 없습니다.

3. 바깥으로 보내는 정보

  • Anthropic(Claude): 할 일을 뽑고 요약하기 위해 넣은 글과 사진을 보냅니다.
  • 구글 캘린더(연결한 경우만): 고른 할 일의 제목, 날짜, 시각, 근거 문장을 내 기본 캘린더에 일정으로 넣고, 고치거나 지웁니다.
  • 네이버 캘린더(연결한 경우만): 위와 같습니다.

광고에 쓰거나, 팔거나, 위에 적지 않은 곳에 넘기지 않습니다.

4. 구글 사용자 데이터

  • 요청하는 권한은 https://www.googleapis.com/auth/calendar.events 하나입니다.
  • 이 권한으로 말한대로가 만든 일정만 만들고, 고치고, 지웁니다. 캘린더의 다른 일정은 읽거나 보관하지 않습니다.
  • 구글에서 받은 연결 값은 이 PC의 data/ 폴더에만 저장하고, 캘린더에 일정을 넣는 데에만 씁니다.
  • 말한대로가 구글 API에서 받은 정보를 쓰고 다른 앱으로 옮기는 것은 제한적 사용(Limited Use) 요건을 포함한 Google API 서비스 사용자 데이터 정책을 따릅니다.

5. 지우기와 연결 끊기

  • 할 일: 목록에서 지우기를 누릅니다.
  • 넣은 글·녹음: 넣은 것 탭에서 항목을 열고 이 녹음 지우기를 누릅니다.
  • 캘린더 연결: 화면 아래 캘린더 연결 → 연결 끊기를 누릅니다. 구글 쪽 권한까지 거두려면 구글 계정의 서드파티 연결에서 말한대로를 삭제합니다.
  • 모든 정보를 지우려면 PC 주인에게 요청합니다. data/ 폴더를 지우면 모두 사라집니다.

6. 문의

이 앱을 설치한 PC 주인에게 묻거나, 저장소의 Issues에 남겨 주세요.
