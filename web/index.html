                    휴대폰에서 쓰기

                    폰 Chrome에서 아래 주소 열기 → 이름·코드 → 메뉴 「설치 및 바로가기 만들기」

                    설치하면 홈 화면에 아이콘이 생기고, 녹음 앱의 공유 목록에 「말한대로」가 나와요.

                    1. 아래 「설치가 안 돼요」를 펼쳐 주소를 예외로 등록 (한 번만)
                    2. 아래 「지금 설치」를 누르거나, Chrome 메뉴 ⋮ → 「설치 및 바로가기 만들기」
                    설치가 안 돼요 (http 주소라서)

                    폰 Chrome에 이 주소를 예외로 등록하면 돼요.

                    1. 주소창에 chrome://flags/#unsafely-treat-insecure-origin-as-secure
                    2. 칸에 넣고 Enabled → Chrome 다시 시작
                    3. 다시 열어 「설치 및 바로가기 만들기」
